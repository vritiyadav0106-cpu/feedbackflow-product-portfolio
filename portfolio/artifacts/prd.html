FeedbackFlow — PRD summary

MVP v1.0 · Vriti Yadav

Overview

Web tool for capturing user feedback, promoting themes to feature ideas, and prioritizing with RICE — built for early-stage PMs who need clarity without heavyweight product ops software.

Goals

GoalSuccess signal
Faster feedback captureLog an item in under 2 minutes
Consistent prioritizationEvery promoted feature has a RICE score
Clear decisionsCan explain top 3 priorities in a review

Out of scope (MVP)

  • Authentication and multi-tenant workspaces
  • Third-party integrations and automated sentiment
  • Native mobile apps

Core flows

  • Capture: Add feedback with source and submitter type → appears in inbox
  • Promote: Convert inbox item to backlog feature → enter RICE → auto-sort
  • Review: Dashboard highlights volume, top priority, and source mix

Key requirements (P0)

AreaRequirement
InboxAdd, list, and delete feedback; validate minimum detail
BacklogRICE fields with live score calculation and sort
DashboardCounts, top feature by score, source breakdown
DataPersist in browser for demo and usability tests
