# FeedbackFlow

Browser MVP: feedback inbox and RICE prioritization for early-stage product teams.

**Live demo:** https://vritiyadav0106-cpu.github.io/feedbackflow-product-portfolio/feedbackflow/

**Case study:** https://vritiyadav0106-cpu.github.io/feedbackflow-product-portfolio/portfolio/

## Screens

| Tab | Purpose |
|-----|---------|
| Dashboard | Metrics, source breakdown |
| Inbox | Add feedback, promote to features |
| Backlog | RICE scoring, ranked priority list |

Data is stored in browser `localStorage` only.
