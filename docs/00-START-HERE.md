# Start Here — Your APM Portfolio Journey

Welcome. This folder is your **learning map**, not a code manual.

You built (or will present) **FeedbackFlow** — a lightweight tool that helps small product teams collect user feedback and prioritize what to build next using the **RICE** framework.

As an Associate Product Manager applicant, your job in interviews is **not** to explain JavaScript. Your job is to explain:

1. **What problem** you chose and **for whom**
2. **How you decided** what to build (and what to cut)
3. **How you would measure** success
4. **What you learned** and what you would do next

The working app proves you can ship an MVP mindset. The documents prove you can think like a PM.
